Landmarks for registration

Mark 3 easily palpable points on the model (e.g. cusp tip 16, cusp tip 26, incisal edge 31). In the headset, tap the same points in the same order on the phantom/patient.

    Headset

    Controls in the headset
    • In the headset you see only the model. No menu, no rays.
    • Menu on/off: controller button B or Y · hand: double pinch in empty space.
    • Grab, move, rotate the model: grip button or trigger (controller) · pinch (hand). Pull apart with two hands = scale.
    • Register: controller button A or X (or “Register” in the menu). Then tap the 3 landmarks on the patient in the same order: hand = pinch exactly at the point, controller = touch the point with the cyan tip of the virtual needle and pull the trigger. A hint in your view shows which point is next.
    • After registration the model is locked. Grabbing is disabled so it cannot shift during treatment. Unlock it via the menu.
    • DVT slice: menu section “DVT slice”: switch axial / coronal / sagittal, step ◀ ▶ by 1 mm, change window and cut the models. With the slice switched on, the thumbstick (up/down) moves the slice smoothly.
    • Follow controller (phantom): fix one controller firmly to the phantom, register, then choose “Follow controller → Left/Right” in the menu. The model now moves with the phantom. The mounted controller ignores all buttons.
